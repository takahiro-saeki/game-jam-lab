# PROJECT CHARGE v5 — FIVE GEAR TREE 仕様書

> 実装基準: 2026-08-04
> テーマ: CHARGE!

## 1. 今回の狙い

PROJECT CHARGEは、機械魔獣へ一入力ごとに直接攻撃し、その場で得たCHARGEを次の強さへ変換する短編クリッカーである。v5では「8個の平坦な強化」から「常に見える5機のギアと、それぞれの専用ツリー」へ変更した。

序盤は手動攻撃が主役になる。中盤から発電とAUTOを接続し、終盤は自動砲・ドローン・奪ったコアが主火力へ育つ。手動操作は消えず、標識、臨界、発電、AUTO過給を指示する役割へ変化する。

## 2. ルート構造

1. 六体の機械魔獣から好きな三体を討伐する。
2. 二体の通常ボスから一体を倒し、通常エンディングへ到達する。
3. 希望すれば同じビルドで残り三体へ続行する。
4. 選ばなかった通常ボスの強化形態を倒す。
5. ARCH SINGULARITYを倒して真エンディングへ到達する。

ゲームオーバーはない。敵固有条件は失敗を罰するものではなく、達成時に討伐を加速させるボーナス目標である。討伐順で敵HPが上がる一方、CHARGE、全ツリー、六獣コア、ボスコアは次戦へ持ち越す。

## 3. 戦闘の基本循環

- CHARGE攻撃は一入力につき一度だけ発生する。長押しによる自動連打はない。
- 通常の手動入力は敵へ即時ダメージを与え、同時にCHARGEを得る。
- AUTO砲は最初から常時稼働し、ツリーを開いている間も攻撃を続ける。
- 敵HPは割合と `現在値 / 最大値` を併記する。
- CHARGEを5ギアのツリーへ投資すると、数値だけでなく攻撃の規則そのものが変化する。
- 零出力発電を取得すると、手動モードをATTACKとPURE CHARGEで切り替えられる。
- PURE CHARGEは与ダメージ0、手動発電6倍。さらに最大10段のAUTO過給を短時間付与する。

## 5. ツリーUI

- タブ、接続線、ノード、詳細パネルを一画面に収める。
- ノードには名称、現在/最大LV、次の費用、LOCK/MAXを表示する。
- 詳細パネルには説明、現在のギア実数値、ロック理由、購入ボタンを表示する。
- 親ノードの必要LV、必要コア、排他取得をロック理由として明示する。
- マウス、タッチ、方向キー、D-pad/左スティックで同じ構造を操作できる。
- `1`〜`5`で直接ギアを開き、`Q` / `E`または肩ボタンでタブを切り替える。
- 討伐地図では全投資CHARGEを無料で返還する。

## 6. セーブと評価基準

- v5専用セーブへCHARGE、投資総額、36ノード、手動モード、コア、敵HP、ルートを保存する。
- 通常ルートは初見18〜25分、真ルートは45〜70分を目標とする。
- 5入力/秒・即時購入の決定論シミュレーションは通常約6.5分、真エンド約15.5分。これは人間の検討時間を含まない効率化下限として扱う。
- 次のプレイテストでは、ツリーを見て自分のビルドを説明できるか、PURE CHARGEとAUTOが作業ではなく判断になるか、終盤に手動連打から自動機構へ主役が移るかを最優先で評価する。
