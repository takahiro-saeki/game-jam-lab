# PROJECT CHARGE v3 プレイテストガイド

> 対象ビルド: 2026-08-04 機械魔獣討伐版
> 目的: 説明の分かりやすさ、攻撃から成長への還元、六戦の個性、真ルートへの継続意欲を判断する

## 帰宅後、最初にすること

1. `http://127.0.0.1:6670/game/?game=project-charge` を開く。
2. 左上の初期化を3秒以内に2回押して、新規キャンペーンを始める。
3. 六体から直感で好きな三体を選ぶ。
4. 得た機械片を8能力のスキルツリーへ使う。迷ったら各カードの「推奨」系統を伸ばす。
5. 三体討伐後、現在のビルドに合う通常ボスを一体倒す。

通常エンドまで、目標は18〜25分。説明書を先に暗記せず、ゲーム画面だけで理解できるかを優先して確認する。

## 最低限の操作

- **CHARGE**: 画面の大ボタン、`Space`、ゲームパッド主ボタン
- **DISCHARGE**: 画面の放電ボタン、`Enter` / `X`、右クリック、ゲームパッド副ボタン
- **AUTO**: 画面のAUTO、`A`、設定したアクティブ能力ボタン
- **能力購入**: カードをクリック、または`1`〜`8`
- **無料リスペック**: 討伐地図右下、`T`、ゲームパッドのMenu / Start
- **言語切替**: 右上、`L`、設定した言語ボタン
- **全初期化**: `R`を3秒以内に2回

## 通常ルートで見てほしいこと

各項目は `良い / 惜しい / 分からない` の三段階で十分。

| 項目 | 判断すること |
|---|---|
| 最初の30秒 | CHARGEしてDISCHARGEすれば攻撃になると理解できたか |
| 還元感 | ダメージ→機械片→能力購入がひと続きに感じられたか |
| 魔獣差 | 装甲、甲殻、高熱、連鎖、ドローン、臨界が別の攻略に感じられたか |
| 画面理解 | 敵の弱点、現在の状態、次の有効行動が読めたか |
| スキルツリー | LV2で次のノードが開くこと、三つの枝の違いが分かったか |
| コア | 倒した魔獣の能力を自分が受け継いだ実感があったか |
| ボス選択 | グリッド・リーチとサーマル・タイタンで迷えたか |
| テンポ | HPや購入費が長すぎず、判断の間も失われていないか |
| 継続意欲 | 通常エンド後、残り三体と真ボスを遊びたくなったか |

特に「何をすればよいか分からなくなった瞬間」と「初めて気持ちよいと思った瞬間」があれば、その時点だけ教えてほしい。

## 真ルート

通常エンドで「真ルートへ続く」を選ぶ。機械片、スキル、コアを維持したまま次を確認する。

1. 4〜6体目の大きなHP上昇を、コア同士の組み合わせで上回れるか。
2. 選ばなかった通常ボスの強化形態が、通常版以上の山場になるか。
3. 真ボスの「六獣封鎖」「回路反転」「特異点充電」を画面表示から攻略できるか。
4. 真エンドまでの合計時間が50〜70分に収まるか。

## PixelLab画像の確認

九体すべて初回立ち絵を実装済み。次の二体は追加3案を作る可能性が高いため、優先して見る。

- **フェイズ・マンティス**: 位相翼の本数と輪郭がゲーム中でも読みやすいか。
- **サーマル・タイタン**: 「機械魔獣」より「人型ロボット」に見えすぎないか。

ほかにもカード上と戦闘画面で印象が違う敵があれば記録する。良い立ち絵はそのまま採用し、弱い敵だけ追加生成する。
