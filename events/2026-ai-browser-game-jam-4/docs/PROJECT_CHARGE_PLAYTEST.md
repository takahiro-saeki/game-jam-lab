# PROJECT CHARGE プレイテストガイド

> 対象ビルド: 2026-08-03 キャンペーン全経路版
> 目的: 素材を増やす前に、20分の通常ルートと約1時間の真ルートがゲームとして成立するか判断する

## 最初のテスト（20〜25分）

事前説明を読まず、PROJECT CHARGEを新規開始する。6回路のうち気になった3つだけを選び、好きなボスを倒して通常エンディングを見る。

確認したいこと:

- マップを見て、各回路で何が変わるか想像できたか。
- 1ステージ目の30秒以内にCHARGE、DISCHARGE、6セル同期を理解できたか。
- 3ステージが背景違いではなく、入力リズム・大放電・熱・連鎖・AUTO・臨界の違いとして感じられたか。
- 8強化から「次はこの2つを揃えたい」と考える瞬間があったか。
- ボス選択時、現在のビルドとの相性で迷えたか。
- 通常エンドだけで一度ゲームを終えても満足できたか。
- 実時間が18〜25分へ収まったか。

通常エンドでは `C` または画面内の「結果をコピー」で記録をコピーできる。ブラウザがクリップボードを禁止した場合はボタンが「コピーできません」に変わるため、その場合はスクリーンショットを使う。

## 続きのテスト（真ルート）

通常エンドの「真ルートへ続く」を選び、同じ資源と強化を維持したまま次を確認する。

1. 残り3回路で、それまで選ばなかった仕組みがビルドへ加わる。
2. 最初に選ばなかったボスが強化形態で出現する。
3. CHARGE SINGULARITYが6セル同期、熱制御、臨界放電の3段階へ変化する。
4. 真エンド到達までの合計時間が50〜70分へ収まる。

## 特に見てほしい比較軸

各項目を `良い / 惜しい / 分からない` の3段階で十分なので記録する。

| 項目 | 判断すること |
|---|---|
| CHARGEの手触り | 長押し・音・火花・数字が気持ちよいか |
| 放電判断 | 部分放電と6セル放電を使い分けたか |
| ステージ差 | 6ルールのうち、好き・嫌いが生まれたか |
| 強化 | 価格と効果を読んでビルドを考えられたか |
| シナジー | 2項目をレベル2へ揃えた時、完成感があったか |
| ボス差 | 吸収対策と高熱維持が別の攻略に感じられたか |
| テンポ | 次の購入・放電・ステージまで待たされたか |
| UI | 次にすること、危険、購入可能状態が読めたか |
| 継続意欲 | 通常エンド後に真ルートを遊びたくなったか |

## 操作とセーブ

- マップ・報酬・強化ラックはマウス、方向キー、D-pad、左スティックで操作できる。
- 言語は `L` または設定済みの言語ボタンでいつでも切り替えられる。
- 進行、資源、強化、現在の回路・ボスは自動保存される。
- `R` / 初期化は全キャンペーンを消す操作。誤操作防止のため3秒以内に2回入力した場合だけ実行される。
- ゲーム選択へ戻ってもキャンペーンは消えない。

## このビルドで意図的に未完成の部分

- 6ステージすべてで同じ仮背景を使用している。
- GRID LEECH以外のボス専用PixelLabスプライトは未統合。
- ステージ固有の敵アニメーション、最終演出、BGMは仮表現。
- 数値は自動攻略では検証済みだが、初見の人間プレイ時間は未確定。

ここで評価するのは物量ではなく、ルート構成、6つのルール、4シナジー、2ボスの選択が「続きを作る価値のあるゲーム」になったかどうか。素材制作はこの判断後に優先順位を固定する。
