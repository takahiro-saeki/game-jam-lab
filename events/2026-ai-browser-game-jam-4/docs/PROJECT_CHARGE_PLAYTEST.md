# PROJECT CHARGE v4 プレイテストガイド

> 対象ビルド: 2026-08-04 DIRECT CHARGE版
> 目的: クリック直後の手応え、CHARGEから強化への還元、コア継承、六戦の違いを確認する

## 最初にすること

1. `http://127.0.0.1:6670/game/?game=project-charge` を開く。
2. 以前の表示が残る場合は再読み込みする。完全な新規テストは左上の初期化を3秒以内に2回押す。
3. 六体から直感で好きな三体を選ぶ。
4. **CHARGE攻撃**で敵を攻撃し、同時に得たCHARGEを8能力へ使う。
5. 三体討伐後、現在のビルドに合いそうな通常ボスを一体選ぶ。

ゲームオーバーはない。敵固有ルールに失敗してもダメージや資源は失わず、成功した時だけ攻略が加速する。

## 操作

- **手動攻撃**: 大ボタンまたは敵をクリック/タップ、`Space`、`Enter` / `X`、右クリック、ゲームパッド主/副/戦闘ボタン
- **AUTO砲**: 開始時から常時ON。操作不要
- **能力購入**: 8枚の能力カードをクリック/タップ、または`1`〜`8`
- **ゲームパッド能力選択**: D-pad / 左スティック、購入は`Start / Options`
- **無料リスペック**: 討伐地図のボタン、`T`、ゲームパッド`Menu / Start`
- **言語切替**: 右上、`L`、設定した言語ボタン
- **全初期化**: `R`を3秒以内に2回

## 通常ルートで確認すること

| 項目 | 確認したいこと |
|---|---|
| 最初の5秒 | クリックが即ダメージになり、同時にCHARGEを得たと理解できるか |
| 最初の購入 | どこへCHARGEを使うか分かり、購入直後に強くなったと感じるか |
| AUTO | 最初から自動攻撃していることが見えるか。手動の邪魔ではなく補助に感じるか |
| 8能力 | クリック、連打、臨界、AUTO、発電、コア特化の違いを読めるか |
| 魔獣差 | 六体のボーナス条件が別の攻略リズムに感じられるか |
| コア継承 | 一体倒した後、得たコアが次戦の効率化に効いていると分かるか |
| 敵HP | 長すぎる停滞区間、または強化が速すぎて敵ルールを見ない区間がないか |
| 通常ボス | グリッド・リーチとサーマル・タイタンの選択に意味を感じるか |
| 継続意欲 | 通常エンド後、残り三体と真ボスを遊びたくなるか |

特に次の三点だけでもレビュー材料になる。

1. 初めて「強くなった」と感じた瞬間。
2. 次に何をすればよいか分からなくなった瞬間。
3. 面白さが止まり、単純作業に変わった瞬間。

## 魔獣の攻略表示

- **ギアモウ**: 12クリック目が4倍。
- **ヴォルトバック**: 50 CHARGE生成ごとに6秒の全攻撃2.1倍。
- **パイア・ワーム**: 能力を買うたび一時オーバードライブ。
- **リレイ・ヒドラ**: 手動とAUTOの交互命中で連鎖倍率。
- **スウォーム・マトリアーク**: 手動で標識し、次のAUTOがまとめて掃討。
- **フェイズ・マンティス**: 解析100%で次のクリティカルを保証。

## 真ルート

通常エンドで「真ルートへ続く」を選ぶ。未使用CHARGE、8能力、全コアを維持したまま進む。

1. 4〜6体目のHP上昇を、複数コアと能力の組み合わせで上回れるか。
2. 選ばなかった通常ボスの強化形態が山場になるか。
3. 真ボス三相の有利条件を、中央の戦闘表示だけで理解できるか。
4. クリアまでに新しい強化判断が続き、単なるHP削りになっていないか。
