# PROJECT CHARGE v6 プレイテストガイド

> 対象ビルド: TIERED OVERCLOCK版
> 目的: 一入力一打撃、Tier解放、終盤のAUTO火力、コア継承、通常/真ルート所要時間を確認する

## 最初にすること

1. `http://127.0.0.1:6670/game/?game=project-charge` を開く。
2. 以前の表示が残る場合は再読み込みする。完全な新規テストは左上の初期化を3秒以内に2回押す。
3. 六体から直感で好きな三体を選ぶ。
4. **CHARGE攻撃**で敵を攻撃し、同時に得たCHARGEを画面下の5ギアへ使う。
5. ギアカードを開き、光っているノードから好きな強化を購入する。
6. 三体討伐後、現在のビルドに合いそうな通常ボスを一体選ぶ。

ゲームオーバーはない。敵固有ルールに失敗してもダメージや資源は失わず、成功した時だけ攻略が加速する。

## 操作

- **手動攻撃**: 大ボタンまたは敵をクリック/タップ、`Space`、`Enter` / `X`、右クリック、ゲームパッド主/副/戦闘ボタン。長押ししても自動連打にはならない
- **AUTO砲**: 開始時から常時ON。操作不要
- **ツリーを開く**: 5枚のギアカード、`1`〜`5` / `T`、ゲームパッド`Menu / Start`
- **ツリー操作**: D-pad / 方向キーでノード選択、`Enter` / ゲームパッド`A`で購入、`Q` / `E`または肩ボタンでギア切替、`Z` / `X`または言語/YボタンでTier切替
- **手動モード切替**: 零出力発電を取得後、戦闘画面の切替ボタンまたは`G` / 設定済み戦闘ボタン
- **無料リスペック**: 討伐地図からツリーを開き「無料リスペック」
- **言語切替**: 右上、`L`、設定した言語ボタン
- **BGM切替**: ヘッダーの `M BGM` または`M`。オフ状態は保存される
- **全初期化**: `R`を3秒以内に2回

## 通常ルートで確認すること

| 項目 | 確認したいこと |
|---|---|
| 最初の5秒 | クリックが即ダメージになり、同時にCHARGEを得たと理解できるか |
| 最初の購入 | どこへCHARGEを使うか分かり、購入直後に強くなったと感じるか |
| AUTO | 最初から自動攻撃していることが見えるか。手動の邪魔ではなく補助に感じるか |
| 5ギア | 手動、経済、AUTO主砲、ドローン支援、討伐核の役割差をカードだけで予想できるか |
| ツリー | 接続線、LOCK理由、必要ランク、購入費、現在効果から次の目標を決められるか |
| PURE CHARGE | 0ダメージと引き換えに6倍発電し、AUTO過給へつながる判断が面白いか |
| 終盤火力 | 手動連打だけでなく、育てたAUTO・ドローンが主火力へ移る感触があるか |
| 魔獣差 | 六体のボーナス条件が別の攻略リズムに感じられるか |
| コア継承 | 一体倒した後、得たコアが次戦の効率化に効いていると分かるか |
| 敵HP | 長すぎる停滞区間、または強化が速すぎて敵ルールを見ない区間がないか |
| 通常ボス | グリッド・リーチとサーマル・タイタンの選択に意味を感じるか |
| BGM | 地図、通常戦、通常ボス、真ボス、エンディングの曲調差と0.85秒の切替が自然か。攻撃音を邪魔しないか |
| 継続意欲 | 通常エンド後、残り三体と真ボスを遊びたくなるか |

特に次の三点だけでもレビュー材料になる。

1. 初めて「強くなった」と感じた瞬間。
2. 次に何をすればよいか分からなくなった瞬間。
3. 面白さが止まり、単純作業に変わった瞬間。

## 魔獣の攻略表示

- **ギアモウ**: 12クリック目が4倍。
- **ヴォルトバック**: 50 CHARGE生成ごとに6秒の全攻撃2.1倍。
- **パイア・ワーム**: 能力を買うたび一時オーバードライブ。
- **リレイ・ヒドラ**: 手動とAUTOの交互命中で連鎖倍率。
- **スウォーム・マトリアーク**: 手動で標識し、次のAUTOがまとめて掃討。
- **フェイズ・マンティス**: 解析100%で次のクリティカルを保証。

## 真ルート

通常エンドで「真ルートへ続く」を選ぶ。未使用CHARGE、5ギアの全ランク、全コアを維持したまま進む。

1. 4〜6体目のHP上昇を、複数コアと能力の組み合わせで上回れるか。
2. 選ばなかった通常ボスの強化形態が山場になるか。
3. 真ボス三相の有利条件を、中央の戦闘表示だけで理解できるか。
4. クリアまでに新しい強化判断が続き、単なるHP削りになっていないか。
5. 通常ボス後のTIER II、六体後のTIER IIIが、新しい成長期に入ったと感じられるか。

## 今回の重点変更

- 敵HPを割合に加えて `現在値 / 最大値` で常時表示
- 5ギアをTIER I〜III、66ノード・257ランクへ拡張
- TIER IIを通常ボス後、TIER IIIを六体討伐後に解放
- 前提ランク、分岐、コア条件、ガトリング/レール砲の排他選択を表示
- 手動長押しオートクリックを廃止し、一入力一命令に統一
- ダメージ0・発電6倍・AUTO過給を行うPURE CHARGEを追加
- AUTO、ドローン、購入経済、コア増幅の終盤スケーリングを強化
- 画面上部にセッション総時間を表示し、各戦闘と購入履歴を計測
- 通常/真エンドで計測JSONをコピーし、ローカルJSONLへ追記
- 人間選定のSuno 5曲を場面別に実装し、クロスフェード、ループ、保存式BGMスイッチを追加
- 主人公を人間選定のPixelLab v6案「ヴォルト・ノマド」へ更新

## 所要時間の記録

エンド画面で `C` または設定済みアクションを押すと、今回の計測JSONをコピーできる。レビュー時は次の三つも文章で残す。

1. 通常エンド到達時の総時間。
2. 真エンド到達時の総時間。
3. 説明を読んだ時間、迷った時間、単純作業に感じた区間。

自動基準値は次で再生成する。

```bash
godot --headless --path events/2026-ai-browser-game-jam-4/godot \
  -s res://tests/project_charge_benchmark.gd
```

固定seedの現行基準は、効率的な5入力/秒で通常約6.4分・真約10.7分、安定した2入力/秒で通常約14.6分・真約21.1分。自動購入は説明や迷いを含まないため、人間の目標時間とは分けて評価する。
