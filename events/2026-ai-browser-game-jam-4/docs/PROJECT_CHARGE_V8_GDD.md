# VOLT NOMAD v8 — PRIME CURRENT

## 目的

既存の通常エンド、アーク・シンギュラリティ撃破、Infinite Modeを壊さず、アーク撃破後に任意の最終章を追加する。最終章は短時間審査の必須条件ではなく、ゲームを気に入ったプレイヤーがさらに深く遊ぶための報酬とする。

## アーク撃破後の分岐

アーク・シンギュラリティ撃破後、セーブ地点は `POST_TRUE_CHOICE` になる。

1. 「地上へ帰還する」: 地核機神エンドロールを再生し、タイトルへ戻る。
2. 「深部信号へ応答する」: OVERLIMITを1つ以上復旧していれば、本当のラスボスへ進む。

地核機神エンドロール後にタイトルの「続きから」を選ぶと、同じ2択へ戻る。したがって、先にエンディングを見ても最終章を失わない。

## OVERLIMIT

OVERLIMITは装備品ではなく、5ギアの恒久的な第IV段階である。

- 装備枠、付け替え、排他選択はない。
- 取得した5種はすべて常時・同時発動する。
- TIER I〜IIIの317ランクとは別集計。既存の全スキル実績を変更しない。
- 無料リスペックでは失われない。
- 対応ギアのTIER I〜IIIを最大にすると復旧可能。
- アーク撃破時の「特異点残滓」はTier IVを開く物語上の鍵として扱い、無料購入には使わない。
- 5種類のOVERLIMITはすべて一律40M CHARGEで永久復旧する。ツリー詳細には復旧数、保有額、必要額、不足額を常時表示する。
- Tier IVは「通常ツリーの続き」ではなく、各ギアの役割を1回だけ反転・完成させるシグネチャー能力とする。そのため1ギア1個を維持する。複数ノード化で収集時間を増やさず、必要なら5種復旧後の全体系統1ノードを将来候補にする。

| ギア | OVERLIMIT | 主効果 |
| --- | --- | --- |
| 撃鉄アーム | 天蓋破砕指令 | 20手動指令ごとに最大HP0.30%破砕＋AUTO斉射 |
| 発電心臓 | 永久太陽炉 | 全CHARGE生成を恒久12倍。生成で8秒間、全出力3.5倍＋最大HP比例損傷 |
| 自律砲座 | 事象地平砲 | 20 AUTOごとに最大HP0.25%消去 |
| 群制格納庫 | 主権群体 | 12 AUTOごとに最大HP0.20%収奪 |
| 機核架台 | 六核神化 | 他OVERLIMIT発動5回ごとに最大HP0.60%破断。単独時にも自律発動 |

取得数に応じて通常出力も 1.8 / 3.2 / 5.5 / 9.0 / 15.0倍へ収束する。これは「5種を全部使える」喜びを明確な数字でも表現するための補助倍率である。

## 本当のラスボス — PRIME CURRENT

1種類のOVERLIMITだけでも撃破可能だが、3〜5種の組み合わせを本来の攻略速度とする。自動ベンチマーク（最大317ランク・5 CPS・seed 144）では、単独OVERLIMITが11.56〜12.84分、5種同時が2.71分。

### 第1形態 — 無冠機神 / THE CROWNLESS ENGINE

- HP 900M
- 6秒ごとに弱点系統が手動 / AUTOで反転。
- 巨大な古代機械としてまだ理解できる外形。

### 第2形態 — 零相聖堂 / NULL CATHEDRAL

- HP 3.6B
- 臨界攻撃または6連続以上の手動指令が有効。
- 人型の身体が開き、戦場そのものへ変わる。

### 第3形態 — 闇堕機天使 / FALLEN MACHINE SERAPH

- HP 14.4B
- 損傷するほど内部電流が露出し、与ダメージが加速。
- 装甲ではなく人格と動力だけが残った最終形態。

各形態の撃破時にセーブされ、再開時は到達済みの形態から続く。第3形態撃破後は9秒の機核崩壊シネマティックを挟み、多段爆発、外殻分解、最期の敵通信、ヴォルト・ノマドの応答を経て真エンディングへ接続する。演出は1秒経過後からスキップ可能。

## エンディング

- 通常エンディング: 既存の `Core of Dawn`。
- 地核機神エンディング: 専用BGMスロット `ending_world`。
- 真エンディング: 専用BGMスロット `ending_true`。
- PRIME CURRENT戦: 形態ごとに独立した `prime_current_form_1` / `prime_current_form_2` / `prime_current_form_3`。
- アートワーク画面: 独立した鑑賞用BGMスロット `artwork_gallery`。

PRIME CURRENT三形態とアートワークは、ユーザー選定済みの専用Sunoマスターへ差し替えた。`ending_true`も専用曲を使用する。`ending_world`のみ既存マスターを独立スロットで使用しており、後から専用曲へ差し替えても画面遷移やセーブを変更する必要はない。

真エンディングは約57秒の自動シネマティック。生成した16:9イラスト4枚を8場面で使い、パン、ズーム、フェード、字幕をGodot側で合成する。各場面は6.5〜8秒で自動遷移し、そのまま自動スクロールする真エンドロールへ接続する。クリック / Enter / Aは次の場面への早送り、Escape / Bまたは画面ボタンはスキップ。終了後はタイトルへ戻り、続きからは `POSTGAME` へ入る。

## 会話・デバッグ通信

- 全6機械魔獣、通常ボス2体、アーク、本当のラスボス3形態に日英の登場会話を持たせる。
- 会話は戦闘を止めない通信ボックスとして、支援演算・敵・主人公の順に自動表示する。
- 開発中はF10でサンプル会話を表示できる。
- Web版は `debug_dialogue=1` と `dialogue_speaker` / `dialogue_speaker_en` / `dialogue_text` / `dialogue_text_en` / `dialogue_duration` / `dialogue_role` (`support` / `player` / `enemy`) をURLへ付けると、任意内容を安全にプレビューできる。ゲーム進行やセーブは変更しない。

## 撃破順インフレーション v11

- スキルとPURE COMMANDの成長感は弱体化せず、6体の機械魔獣だけ撃破順HP倍率を `1 / 3.5 / 7.5 / 250 / 40,000 / 500,000` とする。
- seed 144の自動計測では効率操作が約185 / 90 / 82 / 63 / 50 / 50秒、通常操作が約408 / 209 / 199 / 140 / 107 / 62秒。
- 1体目は従来の導入時間を維持し、5・6体目が新Tier購入中に十数秒で消える問題を解消する。
- HP35%以下の処刑プロトコル、HP50%/25%以下の狩猟子機、PURE COMMAND本体の性能はこの段階では変更しない。

Infinite ModeにWAVE依存の装備枠、OVERLIMIT解禁、専用実績は追加しない。
