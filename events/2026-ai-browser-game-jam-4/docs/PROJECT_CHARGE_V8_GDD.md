# PROJECT CHARGE v8 — PRIME CURRENT

## 目的

既存の通常エンド、アーク・シンギュラリティ撃破、Infinite Modeを壊さず、アーク撃破後に任意の最終章を追加する。最終章は短時間審査の必須条件ではなく、ゲームを気に入ったプレイヤーがさらに深く遊ぶための報酬とする。

## アーク撃破後の分岐

アーク・シンギュラリティ撃破後、セーブ地点は `POST_TRUE_CHOICE` になる。

1. 「地上へ帰還する」: 地核機神エンドロールを再生し、タイトルへ戻る。
2. 「深部信号へ応答する」: OVERLIMITを1つ以上復旧していれば、本当のラスボスへ進む。

地核機神エンドロール後にタイトルの「続きから」を選ぶと、同じ2択へ戻る。したがって、先にエンディングを見ても最終章を失わない。

## OVERLIMIT

OVERLIMITは装備品ではなく、5ギアの恒久的な第IV段階である。

- 装備枠、付け替え、排他選択はない。
- 取得した5種はすべて常時・同時発動する。
- TIER I〜IIIの317ランクとは別集計。既存の全スキル実績を変更しない。
- 無料リスペックでは失われない。
- 対応ギアのTIER I〜IIIを最大にすると復旧可能。
- アーク撃破時に「特異点残滓」を1つ得て、最初のOVERLIMITを無料復旧できる。
- 2個目以降の費用は取得順に20M / 60M / 180M / 540M CHARGE。

| ギア | OVERLIMIT | 主効果 |
| --- | --- | --- |
| 撃鉄アーム | 天蓋破砕指令 | 20手動指令ごとに最大HP0.30%破砕＋AUTO斉射 |
| 発電心臓 | 永久太陽炉 | CHARGE生成で8秒間、全出力3.5倍＋最大HP比例損傷 |
| 自律砲座 | 事象地平砲 | 20 AUTOごとに最大HP0.25%消去 |
| 群制格納庫 | 主権群体 | 12 AUTOごとに最大HP0.20%収奪 |
| 機核架台 | 六核神化 | 他OVERLIMIT発動5回ごとに最大HP0.60%破断。単独時にも自律発動 |

取得数に応じて通常出力も 1.8 / 3.2 / 5.5 / 9.0 / 15.0倍へ収束する。これは「5種を全部使える」喜びを明確な数字でも表現するための補助倍率である。

## 本当のラスボス — PRIME CURRENT

1種類のOVERLIMITだけでも撃破可能だが、3〜5種の組み合わせを本来の攻略速度とする。自動ベンチマーク（最大317ランク・5 CPS・seed 144）では、単独OVERLIMITが11.56〜12.84分、5種同時が2.71分。

### 第1形態 — 無冠機神 / THE CROWNLESS ENGINE

- HP 900M
- 6秒ごとに弱点系統が手動 / AUTOで反転。
- 巨大な古代機械としてまだ理解できる外形。

### 第2形態 — 零相聖堂 / NULL CATHEDRAL

- HP 3.6B
- 臨界攻撃または6連続以上の手動指令が有効。
- 人型の身体が開き、戦場そのものへ変わる。

### 第3形態 — 原初電流 / THE FIRST CURRENT

- HP 14.4B
- 損傷するほど内部電流が露出し、与ダメージが加速。
- 装甲ではなく人格と動力だけが残った最終形態。

各形態の撃破時にセーブされ、再開時は到達済みの形態から続く。

## エンディング

- 通常エンディング: 既存の `Core of Dawn`。
- 地核機神エンディング: 専用BGMスロット `ending_world`。
- 真エンディング: 専用BGMスロット `ending_true`。
- PRIME CURRENT戦: 3形態をつなぐ専用スイート `prime_current`。

専用Sunoマスターが届くまでは、実装確認用に既存曲を別々の仮マスターとして割り当てる。曲の差し替えで画面遷移やセーブを変更する必要はない。

真エンディングは8枚の紙芝居。クリック / Enter / Aで送り、Escape / Bまたは画面右上でスキップできる。最後に真エンドロールを流し、終了後はタイトルへ戻る。続きからは `POSTGAME` へ入り、真エンディング再生と任意のInfinite Modeを選べる。

Infinite ModeにWAVE依存の装備枠、OVERLIMIT解禁、専用実績は追加しない。
