# VOLT NOMAD v4 — DIRECT CHARGE 仕様書

> 実装基準: 2026-08-04 直接攻撃版
> 目的: 「クリックした瞬間に攻撃でき、稼いだCHARGEが次の強さへ返る」ことをゲームの中心に置く。

## 1. ゲームの核

地底で機械魔獣を狩る討伐機兵を操作する、短編アクティブクリッカー。

1. **CHARGE攻撃**を押すたび、敵へ即座にダメージを与える。
2. 同じ入力で、強化通貨でもある**CHARGE**を得る。
3. CHARGEを8系統の能力へ投資し、クリック・AUTO・獲得効率・コアを強化する。
4. 魔獣固有のボーナス条件を狙い、通常攻撃より大きなダメージを出す。
5. 倒した魔獣のコアを恒久統合し、後の戦闘でシナジーを作る。

AUTO砲は開始時から常時稼働する。DISCHARGE、熱、冷却、メルトダウン、資源没収は廃止する。敵のルールを無視しても基礎ダメージは必ず通り、ルールに成功すると攻略が加速する。

## 2. キャンペーン構成

```text
六体から好きな三体を討伐（倒す順で敵HPが上昇）
  ↓
二体の通常ボスから一体を選択
  ↓
通常エンディング
  ├─ 審査向けの一周として終了
  └─ CHARGE・8能力・全コアを保持して真ルートへ
       ↓
     残り三体を討伐
       ↓
     選ばなかった通常ボスの強化形態
       ↓
     真ボス「アーク・シンギュラリティ」
       ↓
     真エンディング
```

ゲームオーバーはない。討伐順のHP倍率は `×1.00 / ×1.62 / ×2.55 / ×5.20 / ×8.10 / ×12.00`。前半三体と通常ボスは初見18〜25分、真ルート全体は寄り道と検討を含め45〜70分を目標とする。判断を省いた5クリック/秒の自動購入テストでは通常ルート約7分、全ルート約15分であり、効率化による短縮余地を残している。

## 3. 基本戦闘

### 手動CHARGE攻撃

- 1入力につき、最低1ダメージと1 CHARGE。
- 0.7秒以内の連打でコンボが続き、打撃倍率が上がる。
- クリティカルは初期4%、基本2倍。
- 大ボタンはクリック、タップ、長押しに対応。敵本体を直接クリックしても攻撃できる。

### 常時AUTO砲

- 初期状態から1秒ごとに0.75ダメージ。
- AUTOの命中も少量のCHARGEを生む。
- OFF操作はなく、手動操作中も並行して攻撃する。
- AUTO威力、間隔、ドローン数を独立して伸ばせる。

### CHARGE

- 現在量を画面上部と攻撃機関に常時表示する。
- 攻撃で得たCHARGEは、その戦闘中でも即座に能力購入へ使える。
- 購入した能力と未使用CHARGEは、次の魔獣・ボス・真ルートへすべて引き継ぐ。
- 地図では無料で全能力をリスペックできる。

## 4. 8系統の能力

全能力は最初から購入可能、各最大LV25。費用はランクごとに指数上昇するため、特化と横伸ばしの両方が成立する。

| 能力 | 役割 |
|---|---|
| 衝撃コイル | クリック威力を毎LV `×1.48`。5LVごとに追加の出力跳躍 |
| 連打ギア | コンボ1段あたりの倍率と最大段数を増やす |
| 臨界演算 | クリティカル率を毎LV `+2.5%`。5LVごとに臨界倍率を増やす |
| オートキャノン | 常時AUTOの一発を毎LV `×1.43` |
| 高速リレー | AUTOの射撃間隔を短縮する |
| ドローンベイ | AUTO威力を補強し、4LVごとにドローンを1機追加する |
| 高効率発電機 | 手動・AUTOのCHARGE獲得量を増やす |
| 共鳴回路 | 所有する全機械核の効果を毎LV `+12%` |

## 5. 六体の機械魔獣とコア

| 魔獣 | 戦闘中のボーナス条件 | 討伐後に得る恒久コア |
|---|---|---|
| ギアモウ | 12回目のクリックが装甲を割り4倍 | 10回目の手動攻撃へ4倍威力の衝撃波を追加 |
| ヴォルトバック | 50 CHARGE生成ごとに甲殻が6秒開き、全攻撃2.1倍 | 累計100 CHARGEごとに追加CHARGEを配当 |
| パイア・ワーム | 能力購入で一時オーバードライブ | 以後すべての能力購入で5秒間オーバードライブ |
| リレイ・ヒドラ | 手動とAUTOの交互命中で最大6連鎖 | 全攻撃が一定確率で追加攻撃へ連鎖 |
| スウォーム・マトリアーク | 手動で子機を標識し、次のAUTOがまとめて掃討 | AUTOドローンを恒久的に1機追加し、AUTO臨界率も上昇 |
| フェイズ・マンティス | 非臨界で解析をため、100%で確定臨界 | 以後の全戦闘でも解析100%の確定臨界を使用可能 |

## 6. 通常ボス

### グリッド・リーチ

- 一定周期で吸収核が3.5秒だけ開く。
- 開いている間に手動8クリックを当てると、8発目が5倍になり25 CHARGEを得る。
- 討伐コア「捕食反転核」は、以後の攻撃出力の0.25%をCHARGEへ還元する。

### サーマル・タイタン

- 手動20クリックで炉心が6秒開く。
- 炉心露出中は手動・AUTOを含む全攻撃が2倍。
- 討伐コア「炉皇耐熱核」は、能力購入によるオーバードライブを3秒延長する。

選ばなかった側は、六体討伐後に大幅なHPを得た強化形態として現れる。

## 7. 真ボス — アーク・シンギュラリティ

三相すべてが「失敗で損をする」ルールではなく、成功すれば加速できるルールになっている。

1. **六獣共鳴（100〜66%）**: 指定された手動/AUTOを10回当てて封鎖を順に破る。正しい系統は1.6倍。
2. **攻撃系統転換（66〜33%）**: 7秒ごとに手動、AUTO、臨界、連打の優勢条件が変わる。該当攻撃は1.65倍。
3. **特異点共鳴（33〜0%）**: すべての攻撃が共鳴値をため、100%ごとにボス最大HP3.5%の自動バーストを起こす。

## 8. セーブと表示

- v4専用セーブを使い、旧版の熱・セル型セーブとは分離する。
- CHARGE、累計CHARGE、8能力、六獣コア、ボスコア、敵HP、ルート位置を自動保存する。
- 日本語/英語、マウス、タッチ、キーボード、リマップ可能なゲームパッドに対応する。
- PixelLabで生成した九体の機械魔獣アートは継続使用し、ゲームルール変更のための再生成は行わない。

## 9. 次のプレイテストで見ること

1. 最初のクリックで「攻撃と通貨獲得」を理解できるか。
2. 30〜60秒以内に最初の能力を買い、数値の伸びを体感できるか。
3. 八能力のどれを伸ばすか、自分なりの理由を持てるか。
4. 六体のボーナス条件が説明なしでも戦闘表示から読めるか。
5. コア獲得後、次の敵が実際に速く倒せると感じるか。
6. 通常エンド時点で、残り三体と真ボスへ進みたくなるか。
