# VOLT NOMAD 最終RC 通しテスト

公開中のitch.io版を、初見プレイヤーと同じ導線で確認するためのチェックリスト。開発用URLやデバッグ機能は使わない。

## テスト前

- [ ] [公開ページ](https://tsgamestudio.itch.io/volt-nomad)を開く
- [ ] ページ上部の `Run game` から起動する
- [ ] 可能なら初回は新しいブラウザープロファイル、または保存データを初期化して開始する
- [ ] ヘッドホン使用時も起動直後の音量に驚かない
- [ ] タイトル、設定、日本語/英語切替、フルスクリーンが操作できる

## 最初の10分

- [ ] 最初の会話とチュートリアルだけで、攻撃・CHARGE・強化・AUTOの関係を理解できる
- [ ] 1体目を直感で選べる
- [ ] 最初の強化を迷わず購入でき、購入直後に強くなったと感じる
- [ ] 敵の固有ルールと現在HP / 最大HPを読める
- [ ] スキルツリーの前提条件、価格、効果、Tierロックを理解できる
- [ ] 文字、攻撃音、BGM、点滅、画面揺れに不快な箇所がない

## 通常エンドまで

- [ ] 2体目・3体目が瞬殺にも停滞にもならず、成長を実感できる
- [ ] コア継承が次の戦闘を速めていると分かる
- [ ] 3体討伐後の通常ボス選択と戦闘が成立する
- [ ] 通常エンド、クレジット、タイトル復帰が正常に進む
- [ ] `つづきから`で通常エンド後の選択へ復帰できる
- [ ] 通常エンド到達時間を記録する

## 完全ルート

- [ ] 残り3体、強化通常ボス、ARCH SINGULARITYを順に進められる
- [ ] PRIME CURRENT三形態で立ち絵・会話・BGMが正しく切り替わる
- [ ] 最終撃破の台詞、爆発、余韻、真エンディング、真クレジットが途中で途切れない
- [ ] 完全クリア後にアートワーク14点とInfinite Modeが開く
- [ ] 再起動後も完全クリア状態、実績、会話記録、アートワークが保存される
- [ ] 完全ルート到達時間を記録する

## 途中復帰と操作

- [ ] 戦闘中にページを閉じ、再起動して破損なく復帰できる
- [ ] マウスまたはタッチ、キーボード、使用する場合はゲームパッドで最後まで操作できる
- [ ] 設定変更が再起動後も保存される
- [ ] 会話OFFでは物語会話だけが自動スキップされ、戦闘警告は残る
- [ ] 会話記録で回収済みの日本語・英語テキストを読み返せる

## レビューで残す5点

1. 初めて強くなったと感じた瞬間。
2. 次に何をすればよいか分からなくなった瞬間。
3. 単純作業に変わった区間。
4. 一番良かった演出・音・会話。
5. 提出を止めるほど重大な不具合の有無。

不具合は「画面名 / 直前の操作 / 起きたこと / 再現回数 / スクリーンショット」を一組にして残す。
