# PROJECT CHARGE v6 — TIERED OVERCLOCK

## 目的

PROJECT CHARGE v6は、クリックで攻撃と資源獲得を同時に行い、育てた自動兵器が主火力へ移っていく機械魔獣ハント・クリッカーである。通常エンドは初見20分前後、興味を持ったプレイヤーは同じビルドのまま真ルートへ進める。

## 進行構造

1. 六体の機械魔獣から三体を選んで討伐する。
2. 二体の通常ボスから一体を選ぶ。
3. 通常ボス撃破で通常エンドと **TIER II** を解放する。
4. 続行すると、残り三体、未選択ボスの強化形態へ進む。
5. 六つの魔獣コアを揃えると **TIER III** を解放する。
6. ARCH SINGULARITYを倒すと真エンドになる。

敗北や資源喪失はない。後に選ぶ敵ほどHPが増えるが、討伐コア、ボスコア、上位ツリーによってプレイヤー側の成長率も上がる。

## 一入力の意味

- **CHARGE攻撃**: 一入力につき一回攻撃し、同時にCHARGEを得る。長押し自動クリックは製品版では無効。
- **AUTO**: ゲーム開始時から常時攻撃する。中盤以降は手動よりAUTO・ドローンを強くするのが基本戦略になる。
- **PURE CHARGE**: ダメージを与えず、通常より多くのCHARGEを発生させ、AUTOを短時間過給する。攻撃と経済を入力ごとに選ぶ。

## 五つのギアと66ノード

全ギア合計は66ノード、257ランク。カードにはTierごとの進捗を表示し、専用ツリーで購入する。

| ギア | 主な役割 | TIER II | TIER III |
|---|---|---|---|
| 撃鉄アーム | 手動威力、連打、臨界 | 手動とAUTOの連携、運動回生 | 深淵破砕、OMEGA打撃、終盤の手動フィニッシャー |
| 発電心臓 | CHARGE生成、購入経済、PURE CHARGE | 深層蓄電、戦果配当、費用圧縮 | 事象銀行、無限発電、永続機関 |
| 自律砲座 | AUTO速度、弾種、主砲 | 二連砲身、位相追尾、装填加速 | 特異点砲、時空リレー、殲滅弾 |
| 群制格納庫 | ドローン数、標識、支援 | 複製工廠、群体同期、回収ドローン | 軍団プロトコル、地平標識、世界蜂巣 |
| 機核架台 | コア継承、全体倍率 | 二重核、ボス核鍛造、共鳴経済 | 六核冠、特異点解読、世界機関鍵 |

TIER IIは通常ボスコア、TIER IIIは六魔獣コアを進行条件にする。上位Tierは単なる小倍率ではなく、AUTO弾数、ドローン数、経済、全体出力など挙動を変える。

## 終盤バランス

- 四〜六体目は初期三体より大きくHPが増え、上位Tierと複数コアのシナジーを使う前提になる。
- 敵最大HPを参照する資源獲得にはビルド投資に応じた上限を設け、HP増加そのものが無限資源にならないようにする。
- 強化ボスと真ボスでは割合ダメージに上限を設け、単発撃破を避けつつ、十分に育ったビルドは明確に速くなる。
- 自動ベンチマークの目安は、5入力/秒の効率プレイで通常約6.4分・真エンド約10.7分、2入力/秒で通常約14.6分・真エンド約21.1分。これは説明を読まず最適購入する機械基準であり、初見人間の目標は通常18〜25分、真エンド45〜70分とする。

## 計測

通常・真エンド到達時に以下を記録する。

- セッション総時間と戦闘時間
- 各敵の戦闘時間、与ダメージ、手動入力数、AUTO命中数、クリティカル数
- 戦闘前後のCHARGEと購入ランク
- 購入・リスペック履歴
- コア、最高ダメージ、総生成CHARGE、ルート結果

結果画面から計測JSONをクリップボードへコピーできる。ローカルでは `user://project_charge_playtests.jsonl` にエンドごとに追記し、同じエンドの重複保存はしない。自動基準値は `tests/project_charge_benchmark.latest.json` に固定seed付きで出力する。
