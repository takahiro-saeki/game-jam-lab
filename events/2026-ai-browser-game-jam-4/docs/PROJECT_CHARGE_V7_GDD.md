# VOLT NOMAD v7 — PURE COMMAND / RECORDS / INFINITE

## 今回確定した範囲

この版は、視認性、PURE COMMANDの恒久化、Tier II / III拡張、実績、Infinite Modeを実装する。Tier IV相当のOVERLIMITと追加の超ボスは意図的に含めず、v7のプレイ評価後に別途設計する。

既存セーブは破棄しない。v5 / v6の戦闘スナップショットとv2のルートスナップショットを読み込み、新規20ノードは未取得、実績は未解除として補完する。

## 成長構成

5ギア、3 Tier、86ノード、317ランク。

- Tier I: 従来の基礎ツリー。最初から利用可能。
- Tier II: 最初の通常ボス核で解禁。各ギア5ノード。
- Tier III: 六獣核の統合で解禁。各ギア5ノード。

Tier II / IIIには従来の幹1・枝2に加え、各枝の先へ1ノードずつ追加した。新規効果はPURE過給上限、周期CHARGE回収、未使用CHARGE変換、購入還流、AUTO臨界、斉射発電、標識保持、指令追撃、割合攻撃、単発上限緩和などへ分散している。

## PURE COMMAND

「零出力発電」の購入時、CHARGE ATTACKはPURE COMMANDへ恒久進化する。切替ボタンと切替入力は廃止する。

- 直接打撃ダメージは0。
- 手動CHARGEは6倍。
- 1指令ごとにAUTO過給を1段蓄積。
- 標識、臨界解析、Twin Trigger、撃鉄衝撃波、Armor Punch、WORLDSPLITTER、追加された指令斉射などの間接効果は残る。
- 撃鉄アームへの投資が死にスキルにならず、手動入力がAUTO軍へ命令を渡す役割へ変わる。
- 旧セーブで通常攻撃が選ばれていても、零出力発電取得済みならロード時にPURE COMMANDへ強制移行する。

キャンペーン進行とは独立して永続保存する。New Huntでキャンペーンを初期化しても解除済み実績は保持する。

3. 六獣討伐
4. 二主獣核統合
5. 真エンディング

タイトルとエンディングから一覧を開け、戦闘中の解除は非同期トーストで通知する。Infinite ModeのWAVE数や到達階層を条件にする実績は作らない。

## Infinite Mode

真エンディング後に選択可能な、敗北と専用実績のない継続育成モード。

- WAVE 1 HP: 600,000,000
- WAVE HP: 前WAVEの1.65倍
- WAVE 1報酬: 2,000,000 CHARGE
- 報酬: 前WAVEの1.8倍
- 9体の既存敵を順番に巡回し、各敵の立ち絵・背景・固有BGMを再利用
- WAVEクリア後は次へ進むか、真エンド結果へ戻る
- 現在WAVE、最高到達WAVE、戦闘状態を保存

目的は、真ボスを先に倒したプレイヤーが残りの標準スキルを完成し、「全スキル最大強化」を取得できるようにすること。Infinite Modeを遊ぶこと自体は達成率へ要求しない。

## 視認性

- Noto Sans JPのウェイトを500から600へ上げる。
- 補助文字色を明るくし、暗背景とのコントラストを改善。
- VOLT NOMADの8〜10px級テキストを10〜12pxへ引き上げる。
- 敵HPはパーセントと `現在HP / 最大HP` を併記。
- スキルカード、Tierタブ、ギア進捗、操作ヒントを優先して拡大。
