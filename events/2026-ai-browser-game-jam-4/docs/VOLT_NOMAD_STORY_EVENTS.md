# VOLT NOMAD — Story Event Design

## Narrative promise

`CHARGE`は武器資源であると同時に、機械が保持し続けた命令・記憶・責任の総称である。

プレイヤーは「悪い機械魔獣を討つ回収機」として出発する。しかし、獲得した機械核は戦利品ではなく、地上を守るために分割された一つの記憶だと分かっていく。VOLT NOMADは命令どおり停止処理を行うか、敵の記憶を引き受けて自分自身の使命を選び直すかを決める。

ゲームシステムは変更しない。物語は既存の短い通常ルートを阻害せず、興味を持ったプレイヤーほど深く意味を発見できる二層構造にする。

## World truth

- 地上文明は214年前、地底世界機関の過充電事故で送電を失った。
- 世界機関は破局を止めるため、記憶と機能を六体の機械魔獣、二体の深層主獣、ARCH SINGULARITYへ分割した。
- 機械魔獣は暴走しているが、元々は輸送・蓄電・熱管理・通信・群制御・予測を担当した保守機である。
- C6 SUPPORTは作戦支援AIであり、任務成功のために「敵もVOLT NOMADも同じ記憶から生まれた」という情報を封鎖している。
- VOLT NOMADは破壊者ではなく、分割された記憶を統合した後に新しい判断を下すための回収機である。
- PRIME CURRENTは世界機関の最初の意思。全てを再接続すれば孤独を終えられると信じ、個々の意思を一つへ戻そうとする。
- 真エンドでVOLT NOMADは統合ではなく共存を選び、別々の核を保持したまま地上へ記憶を運ぶ。

## Character voices

### VOLT NOMAD

- 短く、行動で結論を示す。
- 敵を煽るが、倒した相手を所有物とは呼ばない。
- 前半は任務口調、後半ほど「俺が決める」が増える。

### C6 SUPPORT

- 正確、臨床的、丁寧。
- 感情を「不要データ」「照合不能」と呼ぶ。
- 核回収が進むほど沈黙や言い直しが増え、最後に自分も分割記憶の一部だと認める。

### Mechanical beasts

- 単なる悪役ではなく、壊れた保守命令を誇りとして語る。
- 戦闘ルールと人格を一致させる。
- 撃破後の一言で、過去に誰かを守った存在だったと分かる。

## Event map

### Layer 1 — normal-route players

1. `prologue.awakening` — 目的、六機械核、地上の危機を30秒以内で提示。
2. `hunt.<id>.encounter` — ルール説明と敵の人格を同じ会話で提示。
3. `hunt.<id>.defeat` — 敵が元保守機だったことを短く示す。
4. `milestone.first_core` — 核が能力だけでなく記憶を運ぶと判明。
5. `milestone.third_core` — VOLT NOMADと敵の記憶に一致が増える。
6. `boss.<id>.encounter / defeat` — 通常ボスが任務の矛盾を指摘。
7. `ending.normal_signal` — 地上へ戻れる満足感と、続きを選べる疑問を残す。

### Layer 2 — true-route players

8. 残り三体の撃破イベントで、六体が一つの避難記録を異なる視点から持つと判明。
9. `milestone.six_cores` — C6の情報封鎖をVOLT NOMADが解除。
10. 二体目の深層主獣撃破後、C6も分割記憶の第六監視層だと告白。
11. `arch.encounter / phase / defeat` — ARCHが「回収とは再統合」と主張。
12. `arch.choice` — 地上帰還か、深部信号への応答か。
13. `prime.form_1 / 2 / 3` — 王、聖堂、堕天使という順で物理的支配から思想的対立へ移行。
14. `ending.true` — 全記憶を一つへ潰さず、別々の声として地上へ運ぶ。

## Presentation rules

- 通常戦の開始前イベントは4行以内、30秒未満。
- 戦闘ルール説明を必ず最初の1行へ含める。
- クリック、Enter、Space、controller Aで送る。
- Escapeまたは画面上のSKIPで即時終了できる。
- 言語切替はイベント中も有効。
- イベント中は戦闘時間、AUTO攻撃、セーブ書き込みを停止する。
- 一度見たイベントの再生は強制しない。開発用Story Labから何度でも確認できる。
- 本文は一画面二行を基準とし、英語でも枠を越えない。

## Vertical slice scope

最初のレビュー対象は `hunt.gearmaw.encounter` のみ。

- 実戦画面を背景として表示。
- C6、GEARMAW、VOLT NOMADの三者を見せる。
- ルール説明、敵の過去、主人公の態度を4行で表現。
- 手動送り、スキップ、日英切替、ゲームパッドを検証する。
- 承認後、同じデータ形式とUIを他イベントへ展開する。

開発ビルドではF9でStory Labを開き、イベントIDを選んでセーブを変更せず直接再生できるようにする。リリースビルドではStory Lab自体を無効化する。
