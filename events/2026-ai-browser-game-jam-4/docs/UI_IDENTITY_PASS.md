# PROJECT CHARGE — UI Identity / 脱AI感パス

> Status: PixelLabs 18候補生成・Codex一次評価完了、人間レビュー待ち  
> Review: <http://127.0.0.1:6670> → `UI基盤・脱AI感比較`

## 1. 目的

既存のリアクター、6セル、GRID WRAITHには固有の造形がある一方、HUDは丸角カード、細いネオン枠、中央揃えを多用し、一般的なAI生成ダッシュボードに見えやすい。個別アイコンを増やす前に、画面全体を「古い発電所の一枚の制御盤」として再構成する。

PixelLabsへ完成UI、文字、数値、ゲージの塗りを描かせない。生成物は機械筐体、端子、レール、ソケットだけに限定し、Godotが次を担当する。

- 日本語・英語、数値、入力ヒント
- 押下、ホバー、購入可否、AUTO ON/OFF
- 6セルの正確な個数とゲージ値
- 発光、破損、粒子、警告、色覚補助
- マウス、タッチ、ゲームパッドの当たり判定

## 2. 比較した3方向

| 方向 | 特徴 | 推奨用途 |
|---|---|---|
| A: 重工業スイッチボード | 濃紺鋼板、ボルト、整備レール、シアンの共通バス | 通常UIの基準。本命 |
| B: 高圧セラミック実験設備 | アイボリー絶縁体、黒鉛レール、測定端子 | 研究所ステージ、精密系ビルド、代替スキン |
| C: 侵食された発電所 | 珊瑚色の亀裂、露出配線、シアンの応急修理 | GRID WRAITH警告、ボス、真ルートの状態変化 |

全画面を一方向へ固定する必要はない。通常時をA、敵に侵食された部分だけをCにすると、危険状態が色だけでなく材質と輪郭でも分かる。

## 3. 生成結果

|---|---|---:|---|
| 8モジュールラック | `upgrade-rack-switchboard-a` | 96 | 正確な4×2、共通バス、左右の整備区画で一体の設備に見える |

| 敵ゲージ | `wraith-gauge-corrupted-b` | 93 | 6基の主要セルと侵食配線が普通のHPバーから離れている |
| エネルギー片 | `shard-accumulator-switchboard-b` | 97 | アイコンと数値の空欄があり、偽文字を完全に避けられる |

### 集中修正から得たルール

- PixelLabsは「exactly six」と指定しても7〜10区画を生成することがある。ゲームルール上の正確な個数はGodotで保証する。
- `counter`、`odometer`、`display`は偽数字を誘発する。`completely blank maintenance plate`として生成し、数値を後から重ねる。
- 1枚に3部品を作る場合、文字ではなく形状比で役割を指定すると、操作の違いが残りやすい。
- 透明素材は単体の美しさより、中央の静かなオーバーレイ領域と切り出しやすさを優先する。

## 4. Godot統合仕様

### アップグレード

- ラック画像を4×2カード群の背面に配置する。
- 既存の8枚の塗りつぶし背景を廃止し、購入可能時は対応ソケットと共通バスだけを発光させる。
- カーソル選択中はソケットからリアクターへ短い配線パルスを流す。
- レベルアップ時は数字だけを変えず、ボルト締結、ランプ点灯、アイコンの1px上昇を加える。

### CHARGE / DISCHARGE / AUTO

- 3筐体をアトラス領域として切り出す。
- CHARGEは縦ストローク、DISCHARGEは6端子の順次点灯、AUTOはブレーキ解除と回転で状態を表す。
- 発光色がなくても輪郭と可動部で操作を判別できることを完成条件にする。

### GRID WRAITH

- 生成画像の中央6枠を個別タイル化し、Godot側で必ず6基だけ並べる。
- HP減少で右から枠を割り、内部の侵食を消す。
- 吸収予告時は狙われたセルからゲージへ逆流パルスを送る。
- 数値はゲージ内部へ詰めず、上のラベルまたは端部に置く。

### エネルギー片

- 左ソケットへ既存の`shard-coil-spark-a`を重ね、右の空欄へ等幅数字を描く。
- 報酬獲得時は粒子が画面上の発生点からホッパーへ吸い込まれる。
- 到着時に機械式カウントアップ、短い金属音、1回のシアン発光を同期する。

## 5. フォント方針

フォントだけでAI感は消えないが、素材統合後の仕上げとして二書体を比較する。

- 見出し、操作名、区画ラベル: DotGothic16候補
- 数値、小さい日本語、入力ヒント: M PLUS 1 Code候補
- 長い説明やフォールバック: 現在のNoto Sans JP

10〜11pxの説明文は書体変更だけで済ませず、12px以上、行間、コントラストを同時に確認する。日本語と英語の幅、1280×720、スマホ縮小表示を承認ゲートに含める。

## 6. 深く検討した次の優先事項

1. **入力の快感をUI状態へ結び付ける**  
   CHARGEの押下量、セルへの移動、メーター音、わずかな画面振動を同じタイミングに揃える。装飾を増やすより、1入力の因果を強くする。
2. **部分放電と超放電の判断を見た目で先読みさせる**  
   期待出力、危険度、ボス割込み倍率をDISCHARGE筐体の6端子へ予告し、計算しなくても「今押す／待つ」が分かるようにする。
3. **8アップグレードを4系統に整理する**  
   手動、AUTO、放電、熱管理の共通バスをラック上で色と配線にする。個別アイコン24案はこの分類を固定してから生成する。
4. **ボス侵食を画面全体の状態変化にする**  
   GRID WRAITHの攻撃中だけC素材、赤い逆流、故障音を段階的に増やす。敵画像を置くだけでなくUIが奪われる体験にする。
5. **審査20分ルートの理解速度を計測する**  
   初回CHARGE、初回部分放電、初回超放電、初回購入、ボス警告への反応時間をログ化する。見た目の完成度と操作理解を別々に評価する。
6. **音をUI部品ごとに設計する**  
   ピストン、ブレーカー、リレー、セラミック、侵食ケーブルに異なる短音を割り当てる。素材の物質感が視覚だけで終わらなくなる。
