# PROJECT CHARGE v5 PixelLab素材レビュー

2026-08-04に、主人公3案、5ギア各3案、3ステージ背景各3案の計27案を生成しました。現時点ではすべて比較用素材であり、Godotの本番画面には未採用です。

## 確認方法

1. `tools/art-review` で `npm start` を実行する。
2. <http://127.0.0.1:6670/?batch=v5-protagonist> を開く。
3. 各案の原寸、Codex短評、懸念点を見比べる。
4. 「採用」「保留」「不採用」、5段階評価、必要ならメモを入力して保存する。
5. 上部のバッチ選択で、下記9カテゴリを順番に確認する。

保存結果は `tools/art-review/data/review-manifest.json` に記録されます。

## 判断してほしいポイント

- 主人公は「格好良さ」だけでなく、画面上で手動攻撃の主体に見えるか。
- 5ギアは、説明文を読まなくても役割の違いが伝わるか。
- 背景は、敵や数値UIを載せても主張が強すぎないか。
- 良い案でも、色や部品だけ直したい場合は「保留」にしてメモへ修正点を書く。

レビュー後は、採用された主人公を基準に待機・攻撃・PURE CHARGEのアニメーション差分を作り、5ギアと背景をGodotの実画面へ仮組みして最終確認します。
